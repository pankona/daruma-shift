# だるまおとし（試作）

Game Off 2026（テーマ：SHIFT）向けの試作です。積まれた段を叩き出して、だるまを台に降ろします。

## 遊び方

1. 段の上を押さえる（マウスでもタッチでも可）。押さえているあいだは時間が止まります。
2. そのまま引くと、反対向きに矢印が出ます。長く引くほど強く叩けます（上限あり、上限で矢印が赤くなります）。
3. 離すと、矢印の向きと強さで段を叩き出します。
   - 叩く向きはほぼ横向きに制限されます（縦方向は少しだけ）。
   - 引きが短すぎると叩きません（キャンセル）。
4. 全部が止まってから次の段を狙えます。

だるまが床に落ちたら負けです。叩いた後、全部が止まった時点（または6秒後）で判定します。

### 段の種類

| 見た目 | 性質 |
| --- | --- |
| 木目の茶色 | ふつう |
| 水色 | すべりやすい（摩擦が小さい） |
| 濃い茶色（「重」） | 重い（密度3倍） |

### 面

- 面一　三段：段を全部抜いて、だるまを台に降ろす
- 面二　六段：性質つきの段が混ざる。目標は面一と同じ
- 面三　向こう岸：だるまを右の台へ運ぶ

画面右上の「一・二・三」で面を選べます。「やり直し」でいつでも今の面を最初から始められます。

## ローカルでの開き方

ビルドは要りません。物理エンジン Matter.js を CDN から読むので、インターネット接続が必要です。

- いちばん簡単な方法：`index.html` をブラウザで開く
- ローカルの静的サーバーで開く場合（例）：

  ```sh
  python3 -m http.server 8000
  # ブラウザで http://localhost:8000/ を開く
  ```

## 自動テスト用の口

ブラウザのコンソールなどから `window.__game` を使えます。

- `__game.strike(index, dirX, dirY, power)`：段を番号（下から0始まり）で叩く。`power` は 0〜1。全部が止まっていないときは `false` を返して叩かない
- `__game.state()`：面番号・進行状態・判定結果・各ボディの位置と速度などを返す
- `__game.loadStage(n)`：面 n（1〜3）を読み込む
- `__game.step(n)`：物理を n ステップ同期で進める（ヘッドレスでの確認用）
